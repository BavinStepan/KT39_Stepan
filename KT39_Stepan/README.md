# КТ №39 Пользовательские итераторы (Вариант 1)

Реализован кольцевой буфер, поддерживающий `foreach` (через `IEnumerable<T>` и `yield return`). 
Доработано по замечаниям: добавлен интерфейс `ICircularBuffer<T>`, кастомное исключение `InvalidCapacityException` для проверки емкости, а также интерактивное меню в `Main` через `while(true)` для взаимодействия с пользователем.
